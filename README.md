# BMI Calculator

## Description

This is a Python program that calculates the Body Mass Index (BMI) based on the user's weight and height.

## Features

* Calculate BMI value
* Display the calculated BMI
* Classify BMI into different categories:

  * Underweight
  * Normal Weight
  * Overweight
  * Obese

## Requirements

* Python 3.x

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run the following command:

```bash
python bmi_calculator.py
```

## Sample Output

```
Enter your weight in kg: 70
Enter your height in meters: 1.75
Your BMI is: 22.86
Category: Normal Weight
```
